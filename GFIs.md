# Good First Issues

## Add the remaining states as unverified placeholder rows
Add rows for the states not yet covered with empty caps and a clear unverified note, so contributors can fill them in with primary-source citations.

## Add a per-row citation checker
Add a small panel that lists rows whose source URL is missing or whose last verified date is older than a configurable number of days.

## Add a dataset changelog export
Turn the diff view output into a downloadable changelog CSV with the same state, field, from and to columns.
