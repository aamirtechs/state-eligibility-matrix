How it works

  • Built-in dataset covers about 15 high-volume states with availability, fee cap value and basis, a licensing note, a source URL and a last verified date per row.
  • Fee caps keep their basis: percent of enrolled debt and percent of savings are different numbers and are never conflated.
  • The checker returns one verdict: service unavailable, fee within cap, fee exceeds cap (with the excess amount), or insufficient data, always with the row citation.
  • The diff view lists every row and field that changed between two dataset versions, so a rule change is visible at a glance.
  • Seed values come from public summaries named in the README. This is editable reference data that must be verified with primary sources and counsel, never legal advice.
